# CosmoHydro Emulator Documentation Website

This directory contains the GitHub Pages website for the `cosmohydro_emu` package.

## Files

- `index.html` - Main webpage with complete documentation
- `styles.css` - Styling for the website
- `script.js` - Interactive features (smooth scrolling, copy buttons)
- `assets/` - Figures generated by `examples/basic_usage.ipynb`
- `_config.yml` - GitHub Pages configuration

## Viewing Locally

```bash
cd docs
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploying to GitHub Pages

1. Push the `docs` directory to the GitHub repository
2. Repository settings -> "Pages"
3. Under "Source", select "Deploy from a branch", branch `main`, folder `/docs`
4. Save

The site will be available at `https://nesar.github.io/cosmohydro_emu/`.

## Regenerating the figures

Run `examples/basic_usage.ipynb` (it writes into `docs/assets/`):

```bash
cd examples
jupyter nbconvert --to notebook --execute --inplace basic_usage.ipynb
```
